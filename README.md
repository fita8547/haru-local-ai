# 하루

> 와이파이가 없어도, 내 이야기가 기기 밖으로 나가지 않는 한국어 감정 대화 앱

`하루`는 오늘 힘들었던 일을 털어놓고, 음성 인식 결과를 직접 고쳐 보내며, 답을 소리로 들을 수 있는 Android 로컬 AI 앱입니다. Ollama 서버나 별도 백엔드 없이 `llama.cpp`와 `whisper.cpp`를 앱 안에 포함합니다.

한국 개발자가 로컬 AI·음성 UX·경량 Android 추론을 실험하고 기여할 수 있도록 공개하는 프로젝트입니다.

## 사용 흐름

1. 앱을 처음 열고 **모델 설치하기**를 누릅니다.
2. 공식 Qwen 저장소의 `Qwen3 1.7B Q4_K_M` 모델과 Whisper 다국어 Tiny 모델을 한 번 내려받습니다.
3. 설치가 끝나면 수달을 누르고 한국어로 말합니다.
4. 인식된 문장을 텍스트로 수정한 뒤 보내면, 결과를 한국어 음성으로 읽습니다.
5. 다음 실행부터 저장된 모델을 자동으로 로드하므로 인터넷과 별도 서버가 필요 없습니다.

대화 문맥은 최대 14회 왕복까지만 유지합니다. 14회 답변 뒤 다음 질문 전에 이전 대화 토큰과 KV 캐시를 비우고 시스템 안내만 다시 넣습니다. 날짜가 바뀌거나 30분 이상 사용하지 않아도 같은 정리를 합니다. 모델 파일과 가중치는 유지하므로 매번 다시 다운로드하거나 재로딩하지 않습니다.

## 왜 7B가 아닌 1.7B인가요?

테스트 기기 `SM-A505N`은 총 RAM이 약 3.69GB입니다. Qwen3 1.7B Q4는 0.5B보다 다회 대화와 지시 이해가 낫지만, 약 1.28GB 다운로드와 더 높은 발열을 감수해야 합니다. 앱에서는 `/no_think`로 짧은 대화 모드를 사용합니다.

## 구현

- UI: Flutter, 외부 런타임 패키지 없음
- 추론: 공식 `ggml-org/llama.cpp` Android JNI 바인딩
- 음성 입력: `whisper.cpp` 다국어 Tiny 모델, Android 마이크 7초 녹음
- 음성 출력: Android `TextToSpeech`, 한국어
- 모델 저장: 앱 전용 내부 저장소
- 무결성 확인: 다운로드 후 공식 GGUF SHA-256 검증
- 날짜 표시: 화면에 현재 날짜를 표시하며, 날짜 질문을 할 때만 모델에 전달
- 대화 정리: 14회 왕복, 날짜 변경 또는 30분 유휴 시 대화 문맥/KV 캐시 자동 초기화
- 브랜드 UI: 원본 수달 심볼과 그린 컬러 시스템
- 디자인 원본: `assets/brand/`의 수달 심볼·앱 아이콘 자산
- 하루 알림: 기본 오전 9시에 하루 한 번 알림, 로고 메뉴에서 켜고 끄기

음성 인식은 Android나 제조사 서버를 호출하지 않고 앱 내부의 Whisper 모델로 처리합니다.

## 빌드

최소 Android 버전은 API 30(Android 11), CPU는 ARM64입니다.

```sh
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

`android/llama_cpp/native`에는 재현 가능한 네이티브 빌드를 위해 llama.cpp 소스와 원본 라이선스가 포함돼 있습니다. 모델 가중치는 APK에 포함되지 않습니다.
